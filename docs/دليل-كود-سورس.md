# دليل كود سورس المركز الفرنسي

هذه النسخة مخصصة للمبرمجين وتحتوي واجهة النظام والخادم وقوالب تشغيل وتثبيت، بدون بيانات العملاء أو ملف Excel الفعلي.

## أول تشغيل

1. انسخ `data/main data 2.example.xlsx` إلى `data/main data 2.xlsx` أو أنشئ ملفًا بنفس الصفحات والعناوين.
2. نفذ `npm install`.
3. نفذ `npm start`.
4. افتح `http://localhost:3210`.

## الوصول إلى الملفات

- التعديل على التصميم: `public/style.css`.
- تعديل شاشة أو حدث: `public/index.html` و`public/app.js`.
- تعديل التخزين أو الحسابات أو التقارير: `server.js`.
- تعديل Setup: `installer/FrenchCenter.iss`.

## قبل إرسال أي تعديل

لا ترفع `data/main data 2.xlsx` أو PDF صادر أو ملفات مؤقتة. استخدم ملف مثال فارغ فقط. أضف وصفًا واضحًا لكل commit، واختبر النظام مع Excel تجريبي قبل الدمج.
