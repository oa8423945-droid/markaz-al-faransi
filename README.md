# نظام المركز الفرنسي

نسخة محلية لإدارة المركز، وتحفظ البيانات مباشرة داخل `data/main data 2.xlsx`.

## التشغيل

انقر مرتين على ملف `تشغيل النظام.bat`. في أول تشغيل فقط سيقوم النظام بتجهيز المكونات، ثم يفتح على:

`http://localhost:3210`

يمكن فتح ملف البيانات يدويًا من `فتح ملف البيانات.bat`، كما يمكن تنزيل نسخة Excel من داخل النظام.
