# نظام المركز الفرنسي

نسخة محلية لإدارة المركز، وتحفظ البيانات مباشرة داخل `data/main data 2.xlsx`.

## التشغيل

انقر مرتين على ملف `تشغيل النظام.bat`. في أول تشغيل فقط سيقوم النظام بتجهيز المكونات، ثم يفتح على:

`http://localhost:3210`

يمكن فتح ملف البيانات يدويًا من `فتح ملف البيانات.bat`، كما يمكن تنزيل نسخة Excel من داخل النظام.

## التثبيت على Windows 10 وWindows 11

نزّل `FrenchCenter-Setup.exe` من قسم **Releases** وشغّله. ملف التثبيت يحتوي Node.js ومكتبات النظام، وينشئ اختصار **المركز الفرنسي** على سطح المكتب تلقائيًا.

عند تحديث النظام يحتفظ المثبّت بقاعدة البيانات الموجودة ولا يستبدلها.
